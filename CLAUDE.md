# Exam Scheduler

Served by GitHub Pages at https://jakegoldwasser.github.io/exam-scheduler/ (moved off jake-goldwasser.com at Jake's request, 2026-11-06). The TC Builder only posts the key back to pages in its `OK_FROM` list (this github.io origin and localhost:8765).

Jake's tool (2026-11-06) for assessments that use Exam.net instead of Luddite: schedule Testing Center time for students and make the Testing Center cover sheets. It combines Luddite's alternative-schedule-in-parts picker (the same `DAY` / `PERIODS`, Whole / First half / Second half / Minutes) with the Testing Center Coversheets tool (`jakegoldwasser/testing-center-coversheets`: the cover sheet layout and the pre-filled Google Form, `GFORM`). One file, no server, `noindex`, unlinked; everything is kept in the browser's localStorage (`examScheduler.v1`), the test PDF in the tab only. Each student has their own class time (`s.classDate`, `s.classPeriod`, Jake 2026-11-06: several classes can take the same assessment at different times); a new student starts with the last one's, and a pasted line can name its period ("D period"). Each Testing Center day of a student's schedule is one cover sheet (`sittings`): its first part is the starting period, a second that day the additional period, and the time already spent counts their class part and earlier days. **Coming Up** lists every sitting by day, with Print. The teacher's email and extension start as Jake's (jake_goldwasser, 3983).

**Exam.net** (Jake, 2026-11-06): the Testing Center wants a separate Testing Center copy of the exam with testingcenterud@horacemann.org as its invigilator. Horace Mann's Exam.net account has no invigilator role in Share (that needs an exam coordinator, which the school doesn't have): giving them **Access** in Share is how they invigilate. Each assessment's **Testing Center Copy's Settings** mirror Exam.net's settings page (`ENSET`: General, Student Information, Student Workspace, Accommodations, Cheat Prevention; each "Same as your class's exam" unless changed; time limit Off by default; the last-built settings start the next assessment's, `db.enDefaults`). **Build it in Exam.net…** opens `exam.net/admin/exams#tcbuild=<base64url JSON>` (base64, since Exam.net turns %20 into +), and the **TC Builder** bookmark (`examNetBuilder`, dragged to the bookmarks bar once; `BUILDER_V`, bump it when the builder changes so the page asks for a new drag) runs there as the signed-in teacher: it finds the class's exam in the list (key, else name; else a picker), `POST /api/duplicate/<id>` `{examName}` (→ `exam_id`), `GET` then `PUT /api/exams/<id>` with the whole exam (time limit `automatic_submission_timer`, seconds or null; lockdown `device_security` ONLY_SEB = High, NO_SEB = Medium with `browserSecurityMode` 1–5/10 for leaving full screen, 6 = Disabled; spellcheck `spellChecking`; most tools in the `resources` JSON string), `POST /api/share/<id>` `{shares: JSON string of [{id, email}]}` (it replaces the list; `GET /api/share/<id>`'s `shared` items are `{teacher_id, teacher: {email}}`), reads the copy back to check, and posts the key to the Exam Scheduler tab (`tcbuild-done`), else copies it. An existing exam with the copy's name is updated instead of copied again. Requests carry the `XSRF-TOKEN` cookie as `X-XSRF-TOKEN`. No `//` comments inside `examNetBuilder` (it becomes a `javascript:` URL). Tested 2026-11-06 on throwaway copies (deleted).

**Making the exam here** (Jake, 2026-11-06: "I should be able to make a test start to finish"): the Exam.net panel's **Make it here** (`a.enMode` "build"; **It's already in Exam.net** is the old copy-an-existing-exam path) has the exam's name (`enClassName`), **One for each class** (period letters, `enPeriods`: one exam per period named "name - D"), **The Exam** (questions in Exam.net's own types: Instructions or a passage = `informationBlock`, Written answer = `freeText` with a word limit soft/hard, Short answer = `simpleAnswer` with accepted answers, Multiple choice = `multipleChoice` radio/checkbox, shuffle; a rich field with bold, italics, underline and lists, `cleanHtml` keeping only those) and **Your Class's Exam Settings** (`classSet`, the same `ENSET`, blank = Exam.net's default, the time limit in minutes). `compileQuestions` turns them into Exam.net's builder format, and the TC Builder (v2) makes or updates each class exam, then the Testing Center copy from the first. Exam.net's builder API: `POST /api/builder/exam` `[]` → `{id}`; `POST /api/builder/question` `{subQuestions:[],gradingRules:{},answers:{}}` → `{id, version}`; `PUT /api/builder/question/<id>/version/<v>` with the question; `PUT /api/builder/exam/<bid>` with `[{id, version}…]` (the whole ordered list); an exam's `content` is `{"choice":"builder","examBuilderId":bid,…}`; a duplicate copies its questions into a new builder exam. **Exam.net refuses `POST /api/exams` from outside its editor** (422, empty message, even replaying its own request), so a new class exam is a duplicate of any exam in the list with every setting reset to Exam.net's defaults (`NEW_EXAM`) and its questions replaced. `started` in an exam means Open, not taken, and a PUT can't change it; new exams come out Open or Closed like the exam they were copied from. Updating an exam replaces its questions (the panel warns not to update one students have taken). Tested 2026-11-06 end to end (new, per-class, update), test exams deleted.

**Where a student takes it** (Jake, 2026-11-06; from the Testing Center's 2026-2027 guidelines, Ian Pervil, Sep 10, and Jake's own emails to students): each student's row has **Starts in class** (the default and Jake's usual: the first part with their class, the rest in the Testing Center, `withClass`), **All in the TC** (`withClass: false`: students with accommodations must be offered the whole test there; it starts at their class's period on the class's day) and **Make-up** (all of it there, from the next school day). The guidelines: 1.5× of 45 is 68 minutes, split 45 then 23 if not in consecutive periods; every sitting starts at the start of a period (Second half warns); the cover sheet is due by 4pm the school day before (the form dialog warns); the Testing Center gives Exam.net tests in High lockdown (the app), so the copy's lockdown starts High. A pasted line can say "all in TC".
